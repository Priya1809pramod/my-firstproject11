# Textile Company Data Analytics Project

## Project Title
**Textile Sales, Production & Quality Analytics Dashboard**

## Business Problem
A textile company wants to understand sales performance, profitability, production efficiency,
product demand, regional performance and factory quality.

## Dataset
This project uses a **synthetic dataset created for portfolio/learning purposes**.
It contains 600 order-level records covering January–December 2025.

### Main fields
- Order ID and date
- Product and region
- Customer segment and sales channel
- Factory
- Units sold and unit price
- Revenue and cost components
- Profit and profit margin
- Production units
- Defect rate and waste
- Lead time
- Customer satisfaction

## KPIs
- Total Revenue: ₹149,330,059
- Total Profit: ₹51,890,781
- Units Sold: 577,796
- Average Profit Margin: 34.70%
- Average Defect Rate: 2.79%
- Average Customer Satisfaction: 4.00/5

## Questions Answered
1. Which products generate the most revenue?
2. Which regions contribute the most sales?
3. How does revenue change month by month?
4. Which factories have higher defect/waste rates?
5. What is the relationship between sales, cost and profit?
6. Which areas should management investigate for improvement?

## Tools & Skills
- Excel / CSV data handling
- Python
- Pandas
- Data cleaning and aggregation
- KPI calculation
- Data visualization
- HTML/CSS/JavaScript dashboard
- Business insights

## Files
- `data/textile_sales_production.csv` — raw synthetic dataset
- `data/monthly_summary.csv` — monthly KPI summary
- `data/product_summary.csv` — product performance
- `data/region_summary.csv` — regional performance
- `data/factory_summary.csv` — factory quality metrics
- `analysis/analysis.py` — Python analysis script
- `dashboard/index.html` — GitHub Pages dashboard

## How to Run
### Dashboard
Open `dashboard/index.html` in a browser, or publish the repository using GitHub Pages.

### Python analysis
```bash
pip install pandas
python analysis/analysis.py
```
